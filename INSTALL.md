# Install Instructions (Temporary Add-on)

1. Open Firefox.
2. Go to `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on…**.
4. Select `manifest.json` from this folder.

You should see a new button appear to the right of the address bar. Click it to open the popup showing "Hello from plugin!".

Note: Temporary add-ons are removed when Firefox is closed. To keep it permanently, you must package and sign the extension for release.
